# Segurança

[English](SECURITY.md) | [Português](SECURITY.pt-BR.md) | [Español](SECURITY.es.md)

Projeto experimental, sem janela garantida de suporte de segurança. Sem prazo de resposta contratado. Não publique vulnerabilidades sensíveis, credenciais ou dados privados em issues públicas. O relato privado de vulnerabilidades está habilitado no GitHub. Use [Report a vulnerability](https://github.com/cardozoarthur/canonical-contract-database/security/advisories/new) para relatos sensíveis; não exponha detalhes de exploração em issue pública.

Registry confia no processo proprietário local. Grants de Query/Graph não tornam Registry uma fronteira de rede ou multitenant. Reader não tem ACL própria. Use permissões do sistema operacional, entradas limitadas e backups verificados. Testes simulados de recuperação não certificam quedas físicas de energia.
