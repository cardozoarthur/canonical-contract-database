# Security

[English](SECURITY.md) | [Português](SECURITY.pt-BR.md) | [Español](SECURITY.es.md)

Experimental project; no release currently has a guaranteed security support window. No response-time commitment is offered. Do not post sensitive vulnerabilities, credentials or private data in public issues. Private vulnerability reporting is enabled on GitHub. Use [Report a vulnerability](https://github.com/cardozoarthur/canonical-contract-database/security/advisories/new) for sensitive reports; do not create a public issue with exploit details.

Registry trusts its local owning process. Query/Graph grants do not turn Registry into a network or multitenant boundary. Reader has no independent ACL. Use operating-system permissions, bounded inputs and verified backups. Simulated recovery tests do not certify physical power-loss behavior.
