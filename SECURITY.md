# Security

[English](SECURITY.md) | [Português](SECURITY.pt-BR.md) | [Español](SECURITY.es.md)

Experimental project; no release currently has a guaranteed security support window. No response-time commitment is offered. Do not post sensitive vulnerabilities, credentials or private data in public issues. A private reporting channel must be defined before public launch; none is advertised as operational in this preparation copy.

Registry trusts its local owning process. Query/Graph grants do not turn Registry into a network or multitenant boundary. Reader has no independent ACL. Use operating-system permissions, bounded inputs and verified backups. Simulated recovery tests do not certify physical power-loss behavior.
