# Contribuir

[English](CONTRIBUTING.md) | [Português](CONTRIBUTING.pt-BR.md) | [Español](CONTRIBUTING.es.md)

La API Rust 0.1 es experimental. Describa problema, comportamiento esperado y reproducción mínima. Preserve alcance, compatibilidad, recuperación y autorización. Añada pruebas de comportamiento pertinentes para cambios de código.

Desde engine/: `cargo fmt --all -- --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`, `cargo test --workspace --locked`. Genere documentación con `cargo doc --workspace --no-deps --locked`.

No envíe secretos ni datos privados. Las contribuciones deben proporcionarse bajo los términos duales MIT/Apache-2.0, identificando material de terceros y sus condiciones originales. No se promete plazo de respuesta ni incorporación.
